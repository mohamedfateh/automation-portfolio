# Mohamed Alfateh Shaban — Automation Portfolio

Static portfolio website for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository, for example `automation-portfolio`.
2. Upload the contents of this folder to the repository root (`index.html`, `styles.css`, `script.js`, `assets/`, `.nojekyll`).
3. Open **Repository Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the live `github.io` URL.

For a cleaner URL, rename the repository to `mohamedfateh.github.io`; GitHub Pages will publish it as your user site.

## Before public launch

- Review every photo for confidential plant information.
- Replace any project asset that exposes customer-sensitive IP addresses, recipes, credentials, production data or proprietary drawings.
- Add a custom domain later if desired.
- Keep the CV in `assets/Mohamed_Alfateh_Shaban_CV.pdf` updated.

## Lead generation

The website uses direct WhatsApp, email, LinkedIn and phone CTAs. The enquiry form is serverless: it creates a pre-filled email in the visitor's email client, so GitHub Pages hosting is enough.
